# UAE

Amiga-side programs for controlling the emulator.

| File                | SHA-1                                      | Source        |
|---------------------|--------------------------------------------|---------------|
| `uae-configuration` | `ebf3a1f53be665bb39a636007fda3b3e640998ba` | WinUAE 6.0.3  |

`uae-configuration` is Toni Wilen's tool for changing emulator settings from the Amiga side
("(c) Toni Wilen 2004-2008"), for example `uae-configuration SPC_QUIT 1` to quit the emulator. It is
shipped in the WinUAE zip distribution from www.winuae.net, as `Amiga Programs/uae-configuration`,
with its assembly source (`uae-configuration.s`) in `Amiga Programs/sources.zip`; the source is not
in the WinUAE repository. This copy is identical to the one in `WinUAE6030.zip` (WinUAE 6.0.3,
32-bit), where the file is dated 2008-06-23.
